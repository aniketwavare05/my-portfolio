FREQUENTLY ASKED QUESTIONS

Got questions? We have answers

Everything you need to know before integrating NexusFlow into your stack.

How does NexusFlow differ from traditional CI/CD tools like Jenkins or GitHub Actions? +

Traditional tools rely on verbose, brittle YAML files and slow virtual machine initialization. NexusFlow utilizes isolated microVMs that spin up in under 50 milliseconds, alongside automated dependency caching and visual pipeline orchestration. You can define pipelines via visual flowcharts or clean code (TypeScript/Python).

Do I need to enter credit card details to start the free trial? +

No! Our 14-day free trial on the Growth Team plan gives you full access to all features without asking for any credit card or payment information. If you choose not to upgrade, you automatically transition to the Developer Free tier.

Can I run pipelines on my own private cloud or on-premise infrastructure? +

Yes. NexusFlow supports hybrid and on-premise deployments. You can install our lightweight runner agent inside your private VPC, Kubernetes cluster, or on-premise hardware while managing policies centrally from the NexusFlow dashboard.

How are build minutes calculated across concurrent workers? +

Build minutes are calculated based on active compute time rounded to the nearest second. If two test suites run simultaneously for 3 minutes, only 6 total runner minutes are recorded. Idle containers and pre-warmed runners do not consume your allocation.

How secure is NexusFlow with our proprietary codebase and secrets? +

Security is our foundational priority. NexusFlow uses envelope encryption via AWS KMS and HashiCorp Vault. Your environment variables are encrypted at rest with AES-256-GCM and never logged in plain text. We are SOC2 Type II certified and audited annually.
